# 🛡️ بوت الحماية الشامل

بوت ديسكورد احترافي لحماية السيرفر من: حذف الرولات/الرومات، السبام، الحسابات الجديدة، البوتات الغريبة، الروابط، الكلمات الممنوعة، وغيرها. يشمل نظام نسخ احتياطي واسترجاع، وقوائم موثوقين، ولوق كامل لكل حدث.

جميع الأوامر تُستخدم بوضع علامة **`#`** قبل الأمر مباشرة (مثال: `#protection`)، وأمر عرض القائمة الكاملة هو **`/help`** (سلاش).

---

## 1) التجهيز على Discord Developer Portal

1. اذهب إلى https://discord.com/developers/applications وأنشئ تطبيقًا جديدًا (New Application).
2. من تبويب **Bot**:
   - اضغط **Add Bot**.
   - فعّل الصلاحيات التالية تحت **Privileged Gateway Intents**:
     - `SERVER MEMBERS INTENT`
     - `MESSAGE CONTENT INTENT`
   - انسخ الـ **Token** (سيُستخدم في ملف `.env`).
3. من تبويب **General Information** انسخ **Application ID** (وهو نفسه Client ID).
4. من تبويب **OAuth2 → URL Generator**:
   - Scopes: `bot` و `applications.commands`
   - Permissions المقترحة: `Administrator` (لضمان عمل كل ميزات الحماية بدون مشاكل صلاحيات — لأن البوت يحتاج صلاحية إدارة الرولات، الرومات، الطرد، الحظر، الكتم، وسجل الأحداث Audit Log).
   - افتح الرابط الناتج وادعُ البوت لسيرفرك.

> ⚠️ مهم: ضع رول البوت **فوق** جميع الرولات التي تريد حمايتها/التحكم بها، وإلا لن يستطيع تنفيذ أي إجراء عليها.

---

## 2) تشغيل البوت محليًا

يتطلب Node.js إصدار 18 أو أحدث.

```bash
npm install
cp .env.example .env
```

افتح ملف `.env` وضع فيه:
```
TOKEN=توكن_البوت
CLIENT_ID=آيدي_التطبيق
```

ثم شغّل البوت:
```bash
npm start
```

عند نجاح التشغيل سترى في الطرفية:
```
✅ تم تسجيل الدخول باسم اسم-البوت
✅ تم تسجيل أمر /help بنجاح
```

> يمكنك أيضًا رفع المشروع على أي استضافة تدعم Node.js (Railway، Render، VPS...الخ) وتشغيل نفس الأمر `npm start` مع ضبط متغيرات البيئة TOKEN و CLIENT_ID من إعدادات الاستضافة.

## 3) قائمة الأوامر الكاملة

استخدم `/help` داخل ديسكورد لعرض القائمة الكاملة منظمة في السيرفر، أو راجع الجدول بالأسفل. **كل الأوامر تتطلب صلاحية Administrator.**

### إعدادات الحماية الرئيسية
| الأمر | الوظيفة |
|---|---|
| `#protection` | تفعيل/تعطيل الحماية الرئيسية |
| `#seclog [#روم]` | تحديد روم لوقات الحماية (أو `#seclog off` للتعطيل) |
| `#ranti @شخص` | إضافة/إزالة من يخطى حذف الرولات والرومات |
| `#rantilist` | عرض من يخطون حذف الرولات والرومات |
| `#trust @شخص` | إضافة/إزالة من يخطى الحماية بالكامل |
| `#trustlist` | قائمة من يخطون الحماية كاملة |

### الحدود والإجراءات
| الأمر | الوظيفة |
|---|---|
| `#createlimit <عدد> <ثواني>` | تحديد عدد المخالفات المسموحة قبل تنفيذ الإجراء |
| `#dlimit` | تعطيل الحدود (تنفيذ الإجراء من أول مخالفة) |
| `#procedure <strip\|kick\|ban\|jail>` | تحديد الإجراء عند كل مخالفة (لـ jail: `#procedure jail @رول-السجن`) |

### الاستعادة والحفظ
| الأمر | الوظيفة |
|---|---|
| `#restore @عضو` | إرجاع آخر رولات محفوظة للعضو |
| `#restroles [all]` | إرجاع آخر رول محذوف (أو الكل) |
| `#restrooms [all]` | إرجاع آخر روم محذوف (أو الكل) |
| `#restcategory [all]` | إرجاع آخر كاتقوري محذوفة (أو الكل) |
| `#save` | حفظ نسخة كاملة من رولات وقنوات السيرفر |
| `#backup` | استرجاع كل ما هو مفقود من آخر نسخة محفوظة بـ `#save` |

### حماية الرولات
| الأمر | الوظيفة |
|---|---|
| `#collection @رول` | إضافة/إزالة رول من قائمة الرولات المحمية (لا يعدَّل إلا من موثوق) |
| `#collectionlist` | عرض الرولات المحمية |

### الحماية التفاعلية
| الأمر | الوظيفة |
|---|---|
| `#antijoin [عدد الأيام]` | تفعيل/تعطيل منع الحسابات الجديدة (افتراضيًا أقل من 7 أيام) |
| `#setjoin <kick\|ban\|jail>` | تحديد إجراء الحسابات الجديدة |
| `#antibots` | تفعيل/تعطيل منع إضافة البوتات من غير الموثوقين |
| `#antispam` | تفعيل/تعطيل حماية السبام |
| `#spam <عدد> <ثواني>` | تحديد حد رسائل السبام |
| `#antidelete` | تفعيل/تعطيل حماية حذف الرومات/الرولات/الكاتقوري |
| `#antilinks` | تفعيل/تعطيل حماية الروابط |
| `#links add/remove <دومين>` | إدارة قائمة الروابط المسموحة |
| `#antiword add/remove <كلمة>` | إدارة قائمة الكلمات الممنوعة |
| `#bblock @شخص` | منع شخص من دخول السيرفر |
| `#unbblock @شخص` | إزالة منع الدخول عن شخص |

## 4) ملاحظات تقنية

- التخزين يتم في ملف `data/db.json` (يُنشأ تلقائيًا عند أول تشغيل) — كل سيرفر له إعداداته الخاصة.
- كشف "من نفّذ الإجراء" (حذف رول/روم، إضافة بوت...الخ) يعتمد على **Audit Log**، لذا يجب أن يملك البوت صلاحية **View Audit Log**.
- قائمة `#trust` تعني تجاوز كامل للحماية (يُفضّل حصرها بالإداريين الموثوقين جدًا فقط).
- قائمة `#ranti` تعني تجاوز حماية الحذف فقط (لا تشمل باقي أنظمة الحماية).
